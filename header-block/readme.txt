Bloc d'en-tête personnalisable avec image de fond, overlay réglable et boutons d'appel à l'action.

== Description ==

Un bloc Gutenberg moderne pour créer un header (hero) visuellement éditable :

* Image de fond via Media Library.
* Titre et sous-titre en RichText.
* Couleur et opacité d'overlay ajustables.
* Boutons ou icônes d'appel à l'action avec variantes.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/header-block` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Ajoutez le bloc **Header** depuis l'éditeur de blocs et personnalisez-le.
